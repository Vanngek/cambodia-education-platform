# 投稿チェックリスト（毎回これを確認）

## 公開前
- [ ] タイトル：前半30文字に「誰向け・何がわかるか」を入れる（例：【JLPT N4】【技能実習生】【介護の日本語】）
- [ ] サムネ：文字は大きく10文字以内、顔か表情のあるキャラ、背景は1色
- [ ] 説明欄の1〜2行目に要約（検索結果に出る部分）
- [ ] 目次（タイムスタンプ）を入れる（10分以上の動画は必須）
- [ ] 関連する再生リストへ追加
- [ ] 字幕：日本語字幕 ＋ クメール語（できればベトナム語・ミャンマー語・インドネシア語も）
- [ ] タイトルと説明文の翻訳を登録（Studio → 字幕 → 言語を追加 → タイトルと説明）
- [ ] 終了画面：「次の動画」と「登録ボタン」を最後の20秒に設定
- [ ] 「子ども向けではありません」を選ぶ（子ども向けにするとコメント・広告が制限される）
- [ ] 音楽・画像・キャラの著作権を確認（YouTubeオーディオライブラリの曲を使う）

## ショート専用
- [ ] 「関連動画」に長尺動画を設定（ショート → 長尺への導線。再生時間を増やす一番大事な設定）
- [ ] ハッシュタグは3〜5個
- [ ] 最初の1秒で問題を出す、60秒以内

## 公開後
- [ ] 1時間以内に最初のコメントへ返信し、「固定コメント」で質問を出す（例：「あなたの職場ではどう言いますか？」）
- [ ] Facebook（カンボジアの実習生グループ）、Telegram、TikTokにショートを共有
- [ ] 48時間後に Studio で「インプレッションのクリック率」と「視聴者維持率」をメモ

## 毎週月曜の振り返り（10分）
| 確認すること | 目標 | 悪いときの対策 |
|---|---|---|
| クリック率（CTR） | 4〜8% | サムネとタイトルを変える |
| 最初の30秒の維持率 | 60%以上 | あいさつを短くして、すぐ本題に入る |
| 平均視聴時間（長尺） | 5分以上 | 途中にクイズを入れる、テンポを上げる |
| 12か月の再生時間 | 毎月+300時間以上 | 長尺とライブを増やす |
| 登録者の増加 | 週+20人以上 | ショートの最後に登録のお願いを入れる |

## 収益化以外の収入（今からできる）
- 送り出し機関・監理団体・日本語学校との**タイアップ動画**（登録者数が少なくても、ターゲットが明確なので価値がある）
- LearnHub（このリポジトリのサイト）から**有料の個別レッスン・教材**へ誘導
- 登録者500人＋条件を満たせば**メンバーシップ**（メンバー限定の小テスト・PDF）
